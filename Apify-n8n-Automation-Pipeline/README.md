# Apify + n8n Automation Pipeline

This project demonstrates how to build an automation pipeline using **n8n**, **Apify API**, and **Google Sheets** to collect and process publicly available web data.

## 🚀 Workflow Overview

The automation performs the following steps:
1. Manual trigger to start the workflow  
2. Reads input data from Google Sheets  
3. Sends a request to Apify API  
4. Filters the processed results  
5. Stores final data back into Google Sheets  

## 🧰 Tech Stack
- n8n (workflow automation)
- Apify API
- Google Sheets API
- HTTP Requests
- JSON data processing
